# 研究与产品选图

优先服务研究中的数据对比、机制解释、情景分析；其次服务产品与账号/身份/权限设计。选择依据是读者要回答的问题，不是“已经有哪些模板”。以下不是每篇必须填满的组件清单。

## 1. 研究：把证据、解释和假设分开

| 读者问题 | 优先表达 | 必须确认 | 避免 |
| --- | --- | --- | --- |
| 谁更高、差距多大？ | 点图/条形/哑铃；区间已知时显示区间 | 同口径、分母、期间、单位、样本数 | 只画总量掩盖分母差异；无依据误差条 |
| 总体与分组为何结论不同？ | 总体＋分组小多图；构成比例就近展示 | 分组定义、样本权重、缺失 | 将汇总相关解释成个体或因果结论 |
| 差距来自哪些组成？ | 瀑布/贡献分解；组成用堆积 | 可加性、正负、基期和口径 | 非互斥部分强行凑100%；将相关因素当贡献 |
| 随时间怎样变化，事件在哪里？ | 折线＋事件注释或分面 | 真时间间隔、观测频率、缺失、事件来源 | 连过缺失；把事件发生等同影响已证实 |
| 整体波动或尾部风险怎样？ | 分布/分位区间/箱线/ECDF，按数据条件选 | 原始样本或足够的分布统计、范围和样本量 | 均值代表全部；用光滑曲线编造样本 |
| 是否相关，是否有混杂？ | 散点、分组/分面，必要时残差 | 配对观测、分组和拟合条件 | 用箭头或回归线声称因果 |
| 为什么会发生，作用经过哪里？ | 因果假说图或机制剖面 | 变量、方向、作用条件、已证据化/待验证关系 | 把全部关联画成已验证因果；用图美化弱假设 |
| 一个机制如何分阶段运行？ | 机制图、前后对照、时间带 | 资源、顺序、并行、反馈、停止条件 | 所有事物画成方框链；示意距离暗示时长 |
| 改变假设，结果有多敏感？ | 参数解释器＋结果图/敏感性曲线 | 公式、参数范围、固定量、阈值、适用边界 | 滑块只改数字；把情景当预测概率 |
| 多个参数一起变化？ | 有实际网格计算的热图/情景矩阵 | 两个轴与其余固定假设、可比较色阶 | 在无模型数据时绘制连续“风险地形” |
| 结论在什么条件下反转？ | 阈值图/区间带＋可操作输入 | 判定规则、边界求法、不可判定区域 | 只给推荐点、不说明边界；凭空定义“安全值” |
| 多方案有何权衡？ | 成本—效果散点、对齐矩阵、小多图 | 单位、同口径、约束、缺失与证据强弱 | 任意打分/加权得出唯一最佳；滥用双轴与雷达 |

同一素材可以有三层表达：**观测说明发生了什么；机制说明可能怎样发生；情景计算在给定假设下会怎样。** 不强制三层齐全，也不把解释假说写成数据结论。研究/金融图的实际资料需要可追溯来源；这套绘图方法不负责替代来源核查。

例：AI评测成功率。比较方案用同尺度点图；总体与分组不一致时展示样本构成；检验共同任务结构下的结果时才做重加权情景。重加权是模型计算，不是新实测，也不自动证明方案因果优越。

## 2. 产品：先明确业务语义

| 问题 | 表达 | 必须确认的语义 |
| --- | --- | --- |
| 谁负责、何时交接？ | 泳道流程 | 参与方、交接物、等待、分支、终点 |
| 认证/授权请求如何往返？ | 时序图 | 调用方、接收方、请求/响应、同步/异步、失败 |
| KYC、账号、凭证各在什么状态？ | 状态转换图；不同维度分面 | 状态、事件、守卫条件、回退、终点 |
| 为什么某人能操作某资源？ | 权限求值路径＋作用域；规则用决策表 | 主体、授权、资源、操作、租户、继承、有效期、优先级 |
| 系统内外如何分工？ | 边界架构 | 真实系统/信任/组织边界、成员、接口 |
| 对象如何关联？ | 实体关系/关系网络 | 稳定身份、关系、方向、基数（有依据时） |
| 改版改变了什么？ | 对齐的前后图/差异图 | 对应对象、共同尺度、增加/移除/改变 |

KYC完成、账号启用、凭证有效与操作获准是不同维度，不自动合并。权限继承、拒绝优先级和跨租户规则来自当前材料，不是本skill规定的政策。没有规则就标未知，不补造审批条件或接口时限。

## 3. 一份简短视觉简报

工作记录保留以下必要项，不为单次作图造复杂Schema：

- 问题与结论：读者要做什么判断？结论是观测、假说还是计算？
- 证据与对象：数据来源/口径或稳定对象ID；关系、边界与未知项。
- 变化规则：输入如何影响输出？缺失、边界、超范围和无结果怎样处理？
- 编码含义：位置、长度、线型、箭头、区域、颜色表达什么？
- 交互目的（若有）：改什么 → 重算什么 → 更新什么 → 如何说明。

## 4. 图形承担解释，少靠图外复述

按需要选择“总览定位 → 关键机制 → 变化/证据”。复杂解释可用A/B/C分面，共用对象、轴或图例；分面之间保持可比位置与尺度。不要为每一段造一张等权卡片。

先安排可比较的位置、区域与标注，再接线。差异解释优先保持共同对象位置稳定；机制解释优先把真正难理解的局部放大。图例能由直接标签替代时省去，关键条件就近显示。

交互分三类：查看详情只变焦点；切换视角改变范围/表达；操作机制改变输入并重新计算结果。第三类必须同步呈现新结果与原因，并提供初始场景和重置。不能把一个展开面板叫作模拟器。

一张图如果去掉后不增加理解成本，可能不需要它；如果保留后仍需长篇说明怎么看，应先重构图面，不先增加装饰。
