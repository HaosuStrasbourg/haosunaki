# HaosuNaki v1.0.0 发布说明

日期：2026-10-06

v1.0.0 是 HaosuNaki 的首个公开版本：把“从读者问题选择表达”的方法、共用视觉参数和基础图文工具整理为可本地使用的 skill 仓库。适用于研究报告、方案说明、PRD 与机制解释。

## 本版内容

- **核心方法与规范**：从任务、内容关系到表达选择、组件组合、样式映射和验收；涵盖阅读组织、图表选型、机制图与插画。
- **设计 Tokens**：以 `assets/design-tokens.json` 为共用参数来源，页面构建器和基础 SVG 工具读取同一套颜色、字体、字号、间距与线条参数。默认主题可以替换，方法和语义约束保持稳定。
- **三个 SVG 生成器**：`bar()`、`line()`、`flow()`，分别用于条形图、数值横轴折线和显式坐标机制图。
- **离线 HTML 构建**：合入正文、仓库样式、按需脚本、开源字体与许可；另提供使用说明和可重新生成的演示页。
- **67 项官方参考 URL 索引**：按 10 类读者问题组织，帮助判断适用表达与边界。
- **插画方法与提示词**：A 细线编辑用于正文，C 纸感拼贴用于封面与大幅开篇。实际生图依赖宿主工具。

## 公开分发边界

本版不分发 67 份参考重绘 SVG，也不分发 4 张插画参考 PNG。参考索引保留官方 URL 与使用说明；索引项不是可直接换数据的通用模板，不能据此推断所有图类都有生成器。

原创代码与文档采用 [MIT License](../LICENSE)。`assets/fonts.css` 内嵌的 IBM Plex Mono、JetBrains Mono 和 Lora 分别遵循各自的 SIL Open Font License 1.1，完整声明见[字体许可](../assets/font-licenses.html)。Songti SC、PingFang SC 和 Georgia 仅在 CSS 中引用，不分发字体文件。官方参考内容的权利归原权利人所有。

## 使用与检查

要求 **Python 3.10+**；核心脚本仅使用标准库。在仓库根目录运行：

```sh
python3 examples/build_demo.py
python3 -m unittest discover -s tests -v
```

将[使用说明 HTML](manual.html)或[演示 HTML](../examples/demo.html)下载后在本地浏览器打开。GitHub 文件页和 README 不执行 HTML / JavaScript。

安装与自定义方式见[使用说明](2026-10-06%20-%20使用说明.md)。安装时保留完整仓库目录；已有同名 skill 先备份、比较差异，不直接覆盖。

## 已知限制

- `flow()` 使用显式坐标，不提供自动布局、自动绕线或全面碰撞保证；复杂图需要实际预览。
- 修改 Tokens 后须重新生成输出。历史图稿、复杂布局和插画不会自动适配新主题。
- 离线构建不会自动内嵌正文引用的外部资源；调用者需检查正文资源与脚本。
- 测试命令验证基础行为，不能证明任意新数据、交互或输出媒介已通过验收。此发布说明不宣称完成全面跨浏览器、手机、跨设备字体或 PDF 视觉验收。
- SVG 与 PDF 等静态输出不保留完整 HTML 交互；需要 PDF 时应实际导出并检查。
