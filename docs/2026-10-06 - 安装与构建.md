# HaosuNaki 安装与构建

这里是操作附录。方法和使用示例见[使用说明](2026-10-06%20-%20使用说明.md)。

## 安装为 skill

下载完整仓库，按照所用助手的方式放入个人 skill 目录，形成 `skills/haosunaki/SKILL.md`。保留 `references/`、`assets/`、`scripts/` 的相对位置。若已有同名目录，先备份并比较差异，不直接覆盖。

只复制 `SKILL.md` 会缺少资源。安装 skill 不会自动增加图像生成、浏览器控制或 PDF 导出能力；这些能力由使用的助手和工具提供。

## 阅读与构建

将[说明书 HTML](manual.html)或[示例 HTML](../examples/demo.html)下载后用浏览器打开。GitHub 文件页不执行 HTML 或 JavaScript。

运行要求：Python 3.10+；核心脚本只使用标准库。v1.0.0 发布时使用 Python 3.12.14 完成本地检查。

在仓库根目录重新生成演示：

```sh
python3 examples/build_demo.py
```

制作自己的文档，先写含 `<main>…</main>` 的 UTF-8 正文片段，再合入样式与资源：

```sh
python3 scripts/build_html.py \
  --body body.html \
  --title "方案说明" \
  --output report.html
```

构建器负责组装页面，内容理解与编写由助手或作者完成。输入和输出不能是同一文件；默认拒绝覆盖已有输出，确需覆盖指定文件时使用 `--force`。

正文中的外部图片和脚本不会自动下载内嵌，离线交付需另外检查。正文应来自可信材料，构建器不是安全清洗工具。

## 工具与主题

基础生成器有 `bar()` 条形图、`line()` 折线图和 `flow()` 显式坐标机制图，见[图形接口](../references/2026-10-04%20-%20图形工具接口.md)。复杂统计、空间投影、复杂布局及交互需要单独实现。

[67 项官方参考索引](../references/2026-10-04%20-%20已确认图族与复用索引.md)帮助选表达方式，不代表 67 个通用生成器，也不提供官方图稿的再发布授权。

[design-tokens.json](../assets/design-tokens.json)集中保存颜色、字体、间距等参数。修改后检查：

```sh
python3 scripts/design_tokens.py --check
python3 scripts/design_tokens.py --mapping
```

然后重新生成 HTML 或 SVG。已经导出的旧文件不会自动换肤；复杂图的坐标和换行仍需检查。具体范围见[参数维护](../references/2026-10-05%20-%20设计Tokens与参数维护.md)。

## 验证与输出

核心检查命令：

```sh
python3 -m unittest discover -s tests -v
```

程序测试不等于成品已通过视觉验收。新数据、长标签、手机布局和交互要实际查看与操作。

HTML 构建器不直接输出 PDF；PDF 需要另外导出并检查分页、字体和截断。SVG 不保留网页交互，图外说明也不会自动进入图形导出文件。
