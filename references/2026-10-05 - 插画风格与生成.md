# HaosuNaki 插画风格与生成

2026-10-05 确认：**A 细线编辑插画用于日常正文；C 纸感拼贴用于封面和大幅视觉开篇。** 用户在六张同题样稿中选择 A/C，随后明确第 2、3 类（正文概念场景、轻量辅助配图）均用 A，并确认继续固化。早期“C 主选、A 备选”以此分场景规则为准。B 几何平涂未纳入默认体系。

本文件定义插画分工、风格参考和生成方法。它不替代[数据与机制图选型](2026-10-04%20-%20选图判断树.md)，也不要求每一章都配图。

## 1. 先判断图片承担什么工作

| 任务与位置 | 默认表达 | 边界 |
| --- | --- | --- |
| 封面、专题头图、确需大幅视觉导入的开篇 | C 纸感拼贴 | 建立主题与视觉重心；不给普通章节自动套大图，不挤掉阅读结论 |
| 正文中的概念比喻、人机协作等场景、普通章节配图 | A 细线编辑 | 图片辅助文字，保持细腻、克制，适合连续阅读 |
| 正文旁小配图、连续步骤的辅助插画 | A 细线编辑 | 缩小仍能识别核心动作；步骤顺序、条件与分支由准确文字或机制图承担 |
| 精确数据、流程执行、架构、权限关系、研究证据 | 既有表格／图表／机制图 | 可使用确定性 HTML、SVG 或绘图库；不要用生成插画近似事实、数值或关系 |
| 正文已经足够清楚，图片没有额外作用 | 不加图 | A 是需要正文配图时的默认风格，不是每页必填组件 |

用户明确指定风格时遵从该请求；不要因“封面”二字覆盖用户指定的 A。

“同组”指同一套连续步骤或并列比较插画：组内保持 A 或 C 一种风格。同一文章可用 **C 封面＋A 正文**，也可与已有数据图同页。不要在一张插画中混杂细线与纸片两套主要材质。

## 2. 风格约束

### A · 细线编辑插画

- 纤细、清楚、有轻微手绘变化的深墨轮廓；疏朗构图，形体内部保留开放空间。
- 少量钴蓝局部填色，陶珊瑚只作小面积点题。线条和动作表达优先，避免大色块盖过正文。
- 以少量必要细节增加细腻感；人物比例与动作自然，道具只服务主题。小尺寸下删减细节，避免过细到消失。
- 避免粗黑描边、密集排线、满版纸纹、杂乱草稿感和幼态剪贴画。

### C · 纸感拼贴

- 哑光纸片、轻微不规则的剪裁或撕边、克制的纤维纹理与浅叠压层次。
- 钴蓝纸片构成主要视觉重量，纸白与中性色留出空间，陶珊瑚小面积穿插。
- 纸纹主要落在主体；背景保持干净。阴影只交代纸片叠压，避免厚重立体模型、光泽塑料或脏旧纸面。
- 一个核心概念形成一个主构图，避免装饰道具不断增加。当前样张色块较重，不意味着所有 C 都必须重色；调整时保持纸感，先减少彩色面积与层数。

### 共用约束

- 颜色沿用[设计基准 §2](2026-10-03%20-%20设计规范.md)：纸白 `#FAF8F4`、钴蓝 `#244AC7`、深墨 `#282623`，少量陶珊瑚 `#C45C46`。无需每张集齐颜色。业务含义、冷暖与类别区分优先，不能为追求钴蓝抹掉语义差异。
- 生成图中的色值是目标，不承诺像素精确；页面背景与排版继续用明确 CSS 值。需要透明底时请求真实透明输出，不以纸白冒充透明。
- 普通成品无署名、Logo、水印与默认内嵌文字。标题、数字、步骤标签由 HTML／SVG 排版，沿用五个字体用途。用户确需图片内文字时另行校验，不因图片生成成功就声称字体准确。
- 样稿中的人物、拱门、助手、猫或植物均非固定品牌角色。继承线条、材质与构图节奏，不机械复制道具或把一位示范人物永久固定为形象。
- 比例、主体位置和留白按实际版位决定。参考样张为 3:2，不将其写成所有封面、手机图和小配图的固定比例。

## 3. 风格参考的使用

公开版不附历史试稿。先根据本文件 A／C 的线条、材质与视觉重量约束生成试稿；任务提供有权使用的参考图时，先观察原图，再复用其中的风格。系列内固定同一方向、参考与提示词骨架。

参考图只约束风格，不替代内容设计；不得把参考图片里的文字、商标或精确结构当作默认素材。记录本次使用的来源、授权范围和最终提示词，便于后续稳定复用。

## 4. 生成与交付

1. **确定图片作用。** 从正文提炼一句要表达的概念，确定 A/C、版位、比例、数量及必须保留的对象。已有上下文足够时直接判断；只问会改变主题或用途的缺口。
2. **写场景。** 把抽象概念转成一个容易看懂的主体动作或物件关系。示意隐喻不冒充实测证据、真实事故照片或准确系统拓扑。
3. **固定参考与风格。** 有可用参考时选同方向参考图，否则从文字约束开始；复用本文件对应风格段，替换主题与构图。多张系列沿用同一风格参考；确需同一人物时再明确人物不变量，不把任意漂移当作连续角色。
4. **调用生图能力。** 实际生成或编辑位图时读取环境中的 `imagegen` skill，默认使用内置图像生成工具，按当前工具契约传递参考。没有该能力时说明限制，不静默改成 SVG 占位或新增外部 API。私有业务材料不默认外传；可以从已提供信息中提炼不含敏感细节的公开概念。
5. **查看结果。** 先检查主题、画风、动作与轮廓，再检查实际展示尺寸下的视觉重量和图文关系。有明确缺陷时只针对缺陷做一次修改；仍不合格则交代问题并让用户决定后续，不循环生图。
6. **保存并使用。** 新产物保存到当前任务的交付目录，保留最终提示词与使用的参考记录。不要自动覆盖当前项目已确认的风格参考。HTML 使用本地随包资源或内嵌资源；PNG 不宣称是可编辑矢量。按实际需要提供 alt 文本、图注、PNG 或 PDF 验证。

样式选择获确认，不等于用户授权安装新工具、第三方上传或发布。新图是否替换风格参考，需有用户明确选择；一般成品只进入当前项目。

## 5. 中文提示词骨架

按任务填充，风格段只选 A 或 C。下面是工作模板，不必逐项询问用户。

```text
用途：正文配图／小配图／封面／专题头图。
表达：读者应从图中理解的一句话概念。
主体与动作：具体对象、动作及它们之间的关系；只保留必要道具。
风格参考：有可用图片时注明来源；仅借鉴线条／材质／构图节奏，重新绘制当前主题。
风格：选用下方 A 或 C 段。
构图：适配实际版位与比例，主体完整，留白有明确目的。
配色：纸白背景，钴蓝为主，深墨细节，少量陶珊瑚点题；有业务颜色含义时注明并优先遵守。
文字：默认无文字、数字、Logo、水印、署名；标题与标签由页面单独排版。
约束：一张图表达一个核心概念；不要加入未要求的装饰物或把隐喻画成数据证据。
```

**A 风格段：** 现代编辑插画，细腻而清楚的深墨轮廓，轻微自然手绘变化，少量钴蓝局部填色，大面积干净留白；主体与物件内部保持轻盈开放，动作自然，细节克制。避免厚重描边、密集排线、满版纹理与大面积实色。

**C 风格段：** 现代纸感拼贴，哑光钴蓝纸片与暖纸白组合，轻微剪裁或撕边，细腻但克制的纸纤维；浅叠压与柔和接触阴影表达纸张厚度，主体集中，背景干净。避免厚重立体模型、塑料光泽、脏旧纸面和过多装饰。

使用示例：

- 「用 HaosuNaki 给‘从大量信息中筛出可靠证据’做一张正文配图。」默认 A，选择清楚的筛选隐喻。
- 「给同一篇研究报告做专题封面和两张正文插画。」封面默认 C，正文默认 A；两张正文作为同组保持一致。
- 「画出身份认证失败后的重试条件与权限分支。」走现有精确机制图规范，不调用 A/C 近似流程。

## 6. 最小验收与未验证范围

| 项目 | 通过标准 |
| --- | --- |
| 图文对应 | 看得出核心概念；不添加正文没有的事实或误导性关系 |
| 风格 | A 的细线与轻量填色／C 的纸感与浅层叠压清晰；同组无风格漂移 |
| 阅读重量 | 主体可辨，背景干净；正文图不压过结论，封面不依赖装饰堆叠 |
| 完整性 | 主体无意外裁切，动作合理，无多余肢体、乱码、意外标识 |
| 最终媒介 | 实际查看所需尺寸；嵌入页面后检查图文与手机布局，PDF 按导出成品核验 |
| 保存与状态 | 交付文件存在，提示词与参考可追溯；未验证的跨主题／跨设备稳定性如实保留 |

本轮只固化已选方向与使用边界，在具体任务中按需记录 A/C 风格参考。没有新生成跨题材测试组，没有重新宣称评审 HTML 的实际浏览器交互通过，也没有证明模型每次都能完全复刻。长期一致性通过真实使用中的参考复用、成品检查和用户反馈逐步检验。
