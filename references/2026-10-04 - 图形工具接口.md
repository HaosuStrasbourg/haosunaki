# 图形工具接口

本工具只提供横向／竖向条形图、数值横轴折线、显式坐标机制图，以及少量共用 SVG 原语。图形回答的问题、原始数据、单位、领域色义和机制依据仍由调用方负责。它不是全图类引擎，也不自动进行统计分析、选图、情景计算或关系布局。

## 1. 调用与文件范围

`scripts/figure_primitives.py` 只用 Python 标准库。函数返回完整 SVG 字符串，不写文件、不联网，不修改输入。调用方决定输出路径；覆盖文件仍须符合当前任务授权。

```python
import sys
from pathlib import Path
sys.path.insert(0, "/absolute/path/to/haosunaki/scripts")
from figure_primitives import bar, line, flow, category_colors, THEME

# 对完整类别域生成一次，随后跨图、排序与筛选复用此映射。
colors = category_colors(["model-a", "model-b", "model-c"])
rows = [
    {"id": "model-b", "label": "Model B", "value": 3.1},
    {"id": "model-a", "label": "Model A", "value": 3.4},
    {"id": "model-c", "label": "Model C", "value": None},
]
svg = bar(rows, title="同口径比较", desc="示例输入；Model C 未提供数据。",
          mode="category", color_map=colors, width=720,
          domain=(0, 4), ticks=[0, 1, 2, 3, 4], unit="示例倍数",
          caption="示例数据；缺失不是零。", prefix="example-bar")
Path("/absolute/output/chart.svg").write_text(svg)
```

`prefix` 可省略，默认生成唯一标识；同页显式指定时必须互不重复。需要字节稳定的复现时指定固定 prefix。标题和等价 `desc` 必填；所有可见文本及 ID 会转义。

## 2. 三个高层入口

### `bar(rows, *, title, desc, mode, ...)`

- 行输入：`{"id": 非空唯一字符串, "label": 完整名称, "value": 有限数字或 None}`。
- `orientation="horizontal"`（默认）或 `"vertical"`。均包含零基线，负值向零的另一侧延伸，不裁短柱轴。
- `domain=(min,max)` 可固定同组比较尺度；必须包含全部有效值及零。省略时计算覆盖输入的整洁尺度。
- `ticks` 是显示刻度；可为数值列表，或 `(数值,显示文本)` 列表。不在显示刻度之外加密网格。
- `width=900`，至少 480。竖向类别过密时自动扩大原生宽度（至少每类 64px），不缩字号；调用方读取 SVG 的实际 width。
- `unit`、`caption`、`value_format` 可选。格式函数收到原始数值，只改变文字，不改变几何；建议返回紧凑单位化读数。横条数值列留有固定空间，极长格式需由调用方改为紧凑表达并实际预览。
- `None` 显示“未提供”，不画条；实零保留零标记和数值。所有输入均缺失时保留缺失说明和默认 0–1 参考坐标，不把坐标解释成观测范围。

### `line(series, *, title, desc, mode, ...)`

```python
svg = line(
    [{"id":"scenario", "label":"明确假设下的情景",
      "points":[(1,1.2), (2,None), (3,2.1), (4,2.4)]}],
    title="输入变化与计算结果", desc="合成示例；第二个时点未提供，保留断线。",
    mode="explicitsemantic", color_map={"scenario":THEME["cobalt"]},
    x_domain=(1,4), y_domain=(0,3), x_ticks=[1,2,3,4], y_ticks=[0,1,2,3],
    x_label="输入量", y_label="模型输出（倍）", caption="情景计算，不是预测或置信区间。")
```

- 每条系列必须有 `id`、`points`，`label` 缺省为 ID。点格式 `(数值 x, 数值 y 或 None)`，x 严格递增且不可缺失。日期应先转换成真实数值时间，利用显式刻度文本展示日期，不把时间间距替换成等距类别。
- `None` 终止当前线段，下一有效点另起一段；孤立有效点也显示。无平滑、插值、补点或抽样。未列出的横坐标不自动推断为缺失；调用方必须显式提供缺口。
- 支持 `x_domain/y_domain`、`x_ticks/y_ticks`、`x_label/y_label`、`caption`。同组比较优先固定尺度；折线纵轴不强制含零，刻度必须说明实际范围。所有 y 缺失时使用 0–1 参考域并在图例明示“全部缺失”。
- 图例按实际标签换行；主次网格随显示刻度交替，真实零用较强基线。数值标签 14px，标题 24px；不靠缩字塞内容。

### `flow(nodes, edges, *, title, desc, width=900, caption="", prefix=None, junctions=())`

```python
svg = flow(
    [{"id":"input", "shape":"terminal", "terminal_kind":"start",
      "label":"输入证据\n保留来源", "x":40,"y":110,"width":180},
     {"id":"rule", "label":"明确规则", "x":350,"y":110,"width":180,"emphasis":True},
     {"id":"output", "shape":"terminal", "terminal_kind":"end",
      "label":"计算结果", "x":660,"y":110,"width":180}],
    [{"source":"input","target":"rule","label":"按定义整理"},
     {"source":"rule","target":"output","label":"按公式计算"}],
    title="规则如何产生结果", desc="箭头表示处理顺序；不是因果证明。",
    caption="机制示意，非比例。")
```

- 节点采用图内绝对坐标，`x/y/width` 必填；高度按完整标签自动计算，可显式提供更大的 `height`。显式换行保留，长标签继续换行，不截字。
- 当前普通节点默认白底、中性细边，与纸白图面区分；值读取 `surface.node`，详见[设计 Tokens 与参数维护](2026-10-05%20-%20设计Tokens与参数维护.md)。`emphasis=True` 使用浅蓝填充与蓝边。起止节点可显式传 `terminal_fill`、`terminal_border`（#RRGGBB）作轻量角色区分，省略时仍为中性；这不改变步骤强调或自动表示成功状态。
- `shape` 支持 `process`（默认矩形）、`decision`（真实菱形）、`terminal`（起止胶囊）。菱形只用于条件判断，出线由调用方写明条件；其文字位于中央安全区域，空间不够时增大几何尺寸。
- `number` 仅用于可选的调试／评审定位编号；上例按正式稿省略该字段。正式稿默认省略 `number` 或传 `None`，不要传空字符串；`id` 和完整标签保留。工具不会自动编号、把编号推导为依赖或自动重排。
- 当前工具的编号仍使用旧版左上编号区，并会预留垂直空间；尚未实现最新的角标叠放与菱形／圆形顶部居中。评审图需这些布局时使用定制 SVG；不把说明更新当作渲染器已经升级。最终移除临时编号时，同步修正图注和正文中的编号引用。
- `terminal` 必填 `terminal_kind="start"|"end"`；默认明确标出起点／终点；可选 `terminal_label` 覆盖为简短范围标签，如“本轮开始／本轮结束”。不能把单轮结束等同于全部任务完成。
- 边输入 `source/target`；可选 `label`、`points=[(x,y),...]`（中间路点）、`label_position=(x,y)`。首尾从中心方向求实际矩形、菱形或胶囊边界端口，保留箭头方向。为符合流程规范，用与菱形中心水平／垂直对齐的首末路点，使连线落在顶点；一个顶点只出一根线。调用方安排水平／垂直路段，工具不会自动把斜线转换为直角线。
- 可选 `junctions=[(x,y),...]` 显式标记共享路径的连接点；该点须位于至少两条边上，不因普通交叉自动生成汇合点。
- **无自动布局、自动绕线或全面碰撞保证。** 工具仅拒绝节点包围矩形重叠、线段穿过实际节点形状内部和明显的边标签—节点重叠；这不能发现所有边—边、文字—文字、箭头、复杂布局问题。节点包围矩形与标签避让检查较保守，条件完备性、编号是否唯一仍由调用方验证。若拒绝需调整显式坐标或路点，不删节点和语义分支。实际图面仍须预览。
- 坐标从 SVG 顶部开始，节点 y 必须在自动换行标题区域之后。简单单行标题建议 y≥100。标签较长时增加上下间距。

## 3. 颜色模式须明确

条形和折线必填 `mode`，不默认把所有比较设为蓝灰重点图。

| mode | 输入与约束 |
|---|---|
| `category` | 必须提供完整的稳定 ID→hex `color_map`；平等类别颜色不可重复。不按数据排序位置分色。 |
| `focus` | 必须明确一个当前数据中存在的 `focus_id`；该项蓝、其余中性灰；不可同时传 color_map。已有领域色义时用下项，并以线宽／文字突出对象。 |
| `explicitsemantic` | 必须提供完整 color_map，允许同色。例如单一普通量全部蓝，或采用清楚说明的领域语义。工具不猜测颜色意义。 |

`category_colors(full_domain)` 是一次性映射辅助，默认前三个是钴蓝、珊瑚、湖蓝，兼有冷暖；不默认采用蓝／湖蓝／藤紫的三个相近冷色。默认 6 色不足会报错，不循环。调用方可以传更可辨的显式 `palette`，并在整份报告复用已生成的映射；过滤后的子集不能重新生成颜色。

业务语义、冷暖和实际类别区分优先于品牌。金融红涨绿跌、温度冷暖等要由调用方明确映射；顺序蓝色常量 `BLUE_SEQUENCE` 只提供锚点，不把它用于类别。工具未实施色觉差异或印刷验证。

## 4. 基础原语和主题

- `THEME`、`CATEGORY_PALETTE`、`BLUE_SEQUENCE` 为本接口主题常量；`border=#D7D0C6` 与设计基准的分隔线一致。`assets/chart-theme.css` 只作用于 `svg.hn-chart` 与专用 `hnc-*` 类，不改变阅读页基础 CSS。
- `linear_scale(domain, output)`、`nice_ticks(lo,hi,count=5)`、`wrap_label(text,max_width,size=14)` 可直接复用。
- `SVG(width,height,title,desc,prefix=None,embed_fonts=True)` 提供 `text`、`rect`、`segment`、`grid`、`legend`、`caption`、`render`。低层坐标与属性输入应来自可信绘图代码；不是任意外部 SVG 清洗器。
- `text_width/wrap_label` 使用保守字宽估计，**不是浏览器实际字体度量**。文本不省略不代表所有字形、任意数量对象都已通过视觉验收。标题、图例与普通标签自动增高；很长说明应放图外正文。
- 默认将当前 skill 的 400 字重开源字体及完整许可内嵌；中文与 Georgia 只引用本机，Lora 是内嵌数字回退。SVG 几何、样式、箭头无需网络。跨设备字体与 sharp 字体回退仍须如实说明。

## 5. 情景交互只更新已有图面

`line()` 输出根元素的 `data-x-min/max`、`data-y-min/max`、`data-plot-left/top/width/height`。调用方可用与 Python 相同的线性映射更新已有元素：

```javascript
const d = svg.dataset;
const sx = x => +d.plotLeft + (x-d.xMin)/(d.xMax-d.xMin)*d.plotWidth;
const sy = y => +d.plotTop + +d.plotHeight - (y-d.yMin)/(d.yMax-d.yMin)*d.plotHeight;
```

- 曲线路径：`[data-role="series-segment"]`，附 `data-series`、`data-segment-index`、`data-points`。
- 有效点：`[data-role="series-point"]`，附 `data-series/data-x/data-y`。
- 刻度：`[data-role="axis-x-tick"]`、`axis-y-tick`；网格：`grid-x/grid-y`，均有 `data-value`。
- 条形图根元素也保留 `data-value-min/max` 与绘图区信息；条形保留 `data-id/data-value`。

固定点数、缺失结构与域时可只更新现有坐标；改变缺失结构、系列或节点数量，需要重新调用工具生成图形，不跨空缺强行接线。若域变化，必须同步根域、路径／点、刻度数值及位置、网格、真实零线样式和可见说明。工具不提供浏览器运行时、控件或统计公式；输入验证、计算规则、状态重置、键盘可用性由调用页面负责并实测。

## 6. 最小验收

先核对数据身份与口径，再用一组变化后的输入验证几何确实更新。至少覆盖负值跨零、真实零、`None`、NaN 拒绝、ID 重排颜色稳定、折线断段和节点边界端口。多图对比检查共用域；不能只确认文件能解析。

输出 SVG 在目标宽度实际预览。手机使用明确提示、可聚焦的 `.hn-chart-scroll` 图内滚动，或另做等价重排；不要将整幅带字 SVG 缩成小字。浏览器字体、390/320px页面、交互、PDF和跨设备未测试时分别标记，不用基础测试通过代替成品验收。

公开版的静态 SVG 将 CSS 变量在生成时固化为明确值，以兼容不支持 CSS 变量的图像渲染器。主题更换后重新生成；字体回退仍由查看器决定。
