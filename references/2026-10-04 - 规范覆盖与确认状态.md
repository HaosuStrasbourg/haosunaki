# 公开版覆盖与验证边界

v1.0.0 将方法、表达规则、主题参数和实现工具分开。规则有覆盖，不等于每种表达都有现成生成器；核心测试通过，也不等于任意成品已完成视觉验收。

| 范围 | 随包内容 | 使用边界 |
|---|---|---|
| 方法 | 读者任务、内容语义、选图判断树、组合与验收 | 根据实际材料判断，不为统一风格删减必要信息 |
| 阅读 | 引用、指标、表格、代码、提示框、状态；组合与页面规则 | 长文与紧凑组件分别设密度，交互仍需成品实测 |
| 主题 | JSON Tokens、共用 CSS、字体用途及回退 | 修改参数后重新生成；历史 SVG、定制坐标不会自动迁移 |
| 生成器 | Python 条形、折线、基本机制图；HTML 构建 | 不包含全部统计方法、自动绕线或通用图表运行时 |
| 官方参考 | 67 项外链、适用条件与源例读取注意 | 不分发原图、参考重绘或外部数据；使用前核对来源许可 |
| 插画 | A 正文细线编辑、C 封面纸感拼贴；提示词骨架 | 需宿主提供图像生成；不附模型、服务或历史 PNG |
| 字体 | 内嵌 IBM Plex Mono、JetBrains Mono、Lora 及各自 OFL | Songti SC、PingFang SC、Georgia 仅引用；未保证跨设备一致 |
| 交付 | 自包含 HTML、SVG；使用说明和合成示例 | README 不执行 HTML／JS；PDF 需另行导出并验收 |

## 可重复检查

在仓库根目录运行 `python3 -m unittest discover -s tests -v`，检查核心数据语义、生成与迁移使用。运行 `python3 examples/build_demo.py` 重新生成示例。当前检查详情以本版本发布说明和实际输出为准。

浏览器交互、320／390px 窄屏、跨设备字体、屏幕阅读器与 PDF 不在核心单元测试覆盖范围。每份新成品按具体媒介单独预览和验证；不要引用历史样张作为新稿验收证据。
